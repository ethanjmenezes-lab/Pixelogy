# Pixelogy: The Blacktide Conspiracy

**Locked production story script — v1.0**

This script is the only canonical dialogue. **Do not rewrite, improvise, simplify, translate, or add scripted dialogue.** Every line below maps to a value in `STORY_SCRIPT.json`. Sound effects and action notes are production directions, not on-screen captions.

## Premise

Blacktide Industries secretly creates coastal pollution, then charges cities to clean it up. A young explorer and red crab uncover evidence, defeat security crab trainers, and stop the dumping operation.

## Editorial rules

1. **Exact words**: A scripted speaker or overlay must be displayed exactly as written; do not replace words with Codex-generated copy.
2. **Cinematic, not slides**: Each shot has camera movement, actor behavior, environmental motion, or a transition. Avoid fading between static color panels with text.
3. **Mobile dialogue**: Show a maximum of one speaker bubble at a time, visible long enough to read; advance based on tap as needed.
4. **Respect player pace**: Cinematics can be skipped; first-time viewing is optional; replay in Story Mode; remember playback status.
5. **Gear continuity**: The companion crab uses the player’s current loadout in story scenes, or the baseline crab if the player has not equipped gear. An opening bottle cap is a brief cinematic prop, not an automatically granted inventory item.
6. **No false cleanup claims**: Victory halts fictional dumping and opens restoration efforts, but a battle is not proof that a real-world beach was cleaned.
